# План: поочерёдная сверка секций по фреймам Figma (2026-08-11)

Версия 3. В отличие от версии 2, данные макетов берутся **только через figma-console-mcp** (инструменты `figma_*`, NPX Local Mode: `npx -y figma-console-mcp@latest` + `FIGMA_ACCESS_TOKEN`, WebSocket к плагину Figma Desktop Bridge на портах 9223–9232). Старый `@gethopp/figma-mcp-bridge` (HTTP RPC `localhost:1994`) и Remote SSE (`mcp-remote …/sse`) НЕ используются — они давали обрывы сессий. REST API — только как запасной путь (он троттлится 429).

## Цель

Пройти 10 секций по одной, в порядке таблицы сверху вниз, сверить численные замеры DOM с фреймами макета (структура → размеры → типографика → отступы → цвета → SVG-иконки), исправить расхождения. Каждая секция — отдельный субагент (изоляция контекста).

## Координатное правило

`DOM.y = dump.y - 26` (канвас канвы смещён на 26 вниз). X совпадают напрямую. Замер секции в браузере: `rect.top` относительно `document.documentElement`; сверять по таблице Y/H ниже.

## Порядок проверки внутри секции (не менять)

1. **Структура** — дерево узлов фрейма vs DOM секции (число карточек/ссылок/колонок, вложенность, семантика h1-h3/ul/a).
2. **Размеры** — x/y/w/h каждого элемента из `absoluteBoundingBox` → `getBoundingClientRect`.
3. **Типографика** — `style` TEXT (fontSize/fontWeight/lineHeightPx/letterSpacing) → computed style.
4. **Отступы** — padding/margin/gap/cornerRadius фреймов → CSS.
5. **Цвета** — `fills`/`strokes` (RGB 0..1 → 0..255, alpha) → computed style/background.
6. **SVG-иконки** — `vectorPaths` (d/viewBox) → inline-SVG в `index.html`; нужны файлы → `assets/img/`. НЕ перерисовывать, НЕ брать чужие.
7. **Картинки** — IMAGE-филлы/RECTANGLE: размеры и пропорции; файлы в `assets/img/`.

Расхождение → правка HTML/CSS → повторный замер. Готово → скриншот (`chrome-devtools_take_screenshot` в `C:\Temp\opencode\shot-<секция>.png`) → запись результата в раздел «Ход работ» этого файла (секция = checkbox + строка итога).
