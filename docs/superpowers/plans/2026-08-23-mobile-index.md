## Решения (утверждены)

- Реализуем только брейкпоинты **≤768 и ≤375**, планшет не трогаем.
- Кнопка поиска в мобильной шапке — визуальная заглушка (страницы поиска нет).
- Футер — БЕЗ дубля разметки: уже две карточки `.footer__brand` / `.footer__right`, на мобилке колонка.
- Карусели — Swiper (переиспользуем initSwiper), размеры слайдов через media.css.
- Правила адаптации — в AGENTS.md (раздел Mobile adaptation) + FIGMA.md.
- Дубликаты разметки — только для мелких элементов, чьё положение меняется (кнопки секций, поиск).
