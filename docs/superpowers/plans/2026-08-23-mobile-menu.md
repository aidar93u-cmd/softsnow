# Мобильное меню — сверка с Figma 1742:13439

Дата: 2026-08-23. Макет: «Главная (Меню)» node `1742:13439` (375×812).

## Что сделано

Модель макета: тёмная подложка `rgba(0,0,0,0.6)` + светлая карточка `--bg-light`
(r12, inset 12px), верх карточки — существующая шапка (Navbar 64px: лого + поиск
40×40 + бургер 40×40, белый круг, сепаратор), без дублей разметки.

### js/main.js
- Убрано удаление `.header__caret` у клонов ссылок — в макете шевроны у
  «Отрасли»/«Решения» остаются.
- Клик по подложке (вне панели) закрывает меню.

### css/media.css (блок ≤768, хвост)
- `.mobile-menu`: подложка `rgba(0,0,0,.6)`, без паддингов.
- `body.menu-open .header`: fixed top 8px, left/right 12px — шапка становится
  верхом карточки (r12 сверху уже есть), container-паддинги сняты.
- `.mobile-menu__inner`: панель top 72px (8+64), left/right 12px, r12 снизу,
  паддинг `[8,16,32]`, max-height + скролл.
- Ссылки: 14px/500, lh 1.3, шаг 34px (pad 8px), без подчёркиваний-разделителей.
- Телефон: 14px/500, `rgba(34,34,34,.7)`.
- CTA: full width, h46 (`--control-h`), r28.
- Багфикс root cause: `--color-dark` не существует → полоски бургера были
  прозрачными (в т.ч. на планшете). Заменено на `--color-black` (2 места).
- Багфикс: бургер на мобильном 40×40 (был 46 = `--control-h`), как в макете.
