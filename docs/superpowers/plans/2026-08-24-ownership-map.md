# Карта владения css/sections.css → страницы

Сгенерировано скриптом 2026-08-24 (Task 5). Методика: каждый селектор верхнего уровня → его CSS-классы → страницы, где встречаются все классы блока (пересечение). «Строго одностраничное» = каждый токен селектора встречается ТОЛЬКО на этой странице — такие правила безопасно переносить в css/pages/<page>.css.

## Сводка

- Всего правил с селектором: 730
- Строгих одностраничных (→ css/pages/*): **376**
- Строгих мультистраничных (→ остаются в ядре): 283
- Прочие (JS-dynamic, global, loose-пересечения): ~71 — остаются в ядре
- JS-dynamic (classList/main.js-шаблоны): 24 правила — остаются в ядре рядом с init-логикой
