# Адаптация сайта 1920 → 375 — дизайн

Дата: 2026-08-21
Статус: согласовано с пользователем (полный диапазон до 375px, скейл-подход, fullscreen-бургер, слайдеры остаются каруселями, мобильный макет в Figma отсутствует — верстаем сами).

## Решения

1. **Один файл для всех медиа-правил**: `css/media.css`. Подключается во всех страницах **последним** (после `sections.css`), чтобы каскадно перебивать все остальные файлы при той же специфичности. Существующий `@media` футера из `sections.css` переносится туда. Новые медиа-правила больше НЕ добавлять в другие файлы.
2. **Три яруса** (см. ниже). Основа — rem-архитектура: масштабирование через `html { font-size }` и переопределение токенов на брейкпоинтах.
3. **Слайдеры** остаются каруселями — `breakpoints` в конфигах Swiper (`js/main.js`).
4. **Бургер**: fullscreen overlay, новый компонент `.header__burger` + `.header__menu` в `components.css`, JS-toggle в `main.js` с блокировкой скролла.
5. Без второго DOM и без новых библиотек — только CSS-переопределения.

## Ярусы

| Ярус | Ширина | Механика |
|------|--------|----------|
| A. Зум | ≥1201px | `html { font-size: clamp(10px, 0.8333vw, 16px) }` — пропорциональное сжатие всего rem-layout'а |
| B. Планшет | 768–1200px | root 13px; гриды 4→2, 3→2, 5→3; компактный хедер; бургер с ≤992px |
| C. Мобила | <768px | root 14px; переопределение типографики/спейсинга токенами (`--fs-h1: 2.75rem`, `--section-py` и т.д.); гриды → 1–2 колонки; бургер; слайдеры 1–1.5 карточки |

Переопределения токенов по ярусам живут в `media.css` (не в `tokens.css`) — там же, где все остальные медиа-правила.

## Состав работ (порядок)

1. **Фундамент**: создать `css/media.css`, подключить на все страницы, перенести медиа-запрос футера, ярус A, токен-переопределения B/C, аудит фиксированных px в CSS.
2. **Хедер + бургер** (shared, работает на всех страницах сразу).
3. **index.html** по секциям сверху вниз (hero → footer): правки гридов/переносов там, где скейл не справляется.
4. **Общие секции** чинятся один раз: `.cta`, `.footer`, `.clients`, `.projects`, `.events__card`.
5. **Остальные страницы**: solutions → solution-detail → projects → clients → client-detail → events → event-detail → directum → vuz → univer-online.
6. **Слайдеры**: breakpoints в `main.js` (clients 7.8→2.5, partners 4→1.5, projects 2→1, testimonials 3→1.5, events auto остаётся).

## Контракт файлов (обновление AGENTS.md)

CSS становится 5 файлами: `tokens.css` → `utilities.css` → `components.css` → `sections.css` → `media.css`. Зона `media.css`: ТОЛЬКО `@media`-переопределения существующих стилей. Правило: новое адаптивное правило кладётся в `media.css`, а не в файл исходного стиля.

## Верификация

После каждой страницы: resize на 1440 / 1200 / 992 / 768 / 375; проверка `document.documentElement.scrollWidth <= window.innerWidth` (нет горизонтального скролла); геометрия ключевых блоков через computed styles. Финальный визуальный контроль — человеком.

## Не делаем

- Отдельный мобильный шаблон / второй DOM
- Новые библиотеки
- Рефакторинг существующего CSS вне задачи адаптации
