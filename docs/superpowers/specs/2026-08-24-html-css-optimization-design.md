## Фазы

1. **Аудит-отчёт.** Разметка 71 группы дублей «сливать / не сливать» (критерий: одинаковый интент, не случайное совпадение тел). Точная верификация лишних вендоров по exact-классам (`.swiper`, `.swiper-slide`, инициализация в main.js). Инвентарь спрайт-кандидатов из 32 путей.
2. **SVG-sprite.** Собрать `assets/img/sprite.svg`; заменить инлайны постранично на `<use href="assets/img/sprite.svg#id">`. ⚠️ Работает только по HTTP (не file://).
3. **Консолидация CSS.** Слияние в 3 файла по таблице выше; обновление `<link>`; машинная проверка эквивалентности (множество селекторов и порядок правил до == после); удаление css/pages/.
4. **Дедупликация CSS.**
   - Типографика h1–h4 один раз в base.css; из `__title`-правил удаляются совпадающие `font-*` (отклонения от шкалы остаются локально).
   - Группировка одноразмерных паттернов одного интента: `margin-bottom: 5rem` ×20, sea-hover ×18, hidden-state ×17, swiper `overflow: visible` ×6.
   - `transition: all` ×52 → точечные свойства.
   - Хардкод-цвета с ≥3 повторами → токены; одноразовые остаются.
   - Удалить 3 неиспользуемых токена и 5 зарезервированных классов.
   - Flex-комбинации НЕ выносить в утилиты (повторы ≤5, разные комбинации).
5. **HTML-гигиена.** favicon (сгенерировать из лого) на все страницы; `meta description` ×4; OG-теги на все страницы; `defer` на скрипты; снять лишние подключения Swiper/Fancybox; alt ×6 в directum.html; зачистка точечных inline-стилей где тривиально.
6. **main.js.** Ревизия guard'ов init-функций, лёгкая чистка; архитектура «один файл» сохраняется.
7. **Переименования + синхронизация документации.** Батчами по секциям; FIGMA.md в том же коммите; правки AGENTS.md: правило №5 (иконки), структура CSS (3 файла вместо 5+pages), исключение для `!important`, удаление упоминаний зарезервированных классов и квирков, устаревший ownership-map пометить.

## Контрольные метрики успеха

- Дубли тел деклараций: 71 группа → ~0 (легитимных).
- `transition: all`: 52 → 0.
- HTML: −200–300 KB суммарно; иконка = одна строка `<use>`.
- Повторный прогон аудит-скриптов зелёный; визуал не изменён (проверяет пользователь).
